# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code) when working with code in this repository.

## Purpose

GitHub profile README for `haomingkoo` — special repo (`haomingkoo/haomingkoo`) that GitHub renders on the user's profile page (github.com/haomingkoo). Not an application; there is no code to build, run, or test.

## Tech Stack

- Markdown (`README.md`) with shields.io badges
- GitHub Actions (`readme-tools/github-readme-stats-action`) to auto-generate a stats SVG

## Commands

None. There is no install, build, run, or test step — this repo has no source code or package manifest. The only automation is the GitHub Actions workflow below, which runs on GitHub's runners, not locally.

## Architecture

- `README.md` — the profile content itself (bio, tech stack badges, live apps table, blog post links). This is what renders on the GitHub profile page.
- `.github/workflows/grs.yml` — scheduled workflow (`cron: "0 3 * * *"`, plus manual `workflow_dispatch`) that regenerates `profile/top-langs.svg` via the github-readme-stats-action, then auto-commits and pushes the result as `github-actions`.
- `profile/*.svg` — auto-generated stats cards embedded in `README.md`. Do not hand-edit `profile/top-langs.svg`; it is overwritten daily by the workflow. `profile/stats.svg` is referenced but not currently regenerated by the workflow.

## Key Files

- `README.md` — edit this for any content change (bio, links, projects, badges)
- `.github/workflows/grs.yml` — edit this to change the stats-card generation schedule or options
